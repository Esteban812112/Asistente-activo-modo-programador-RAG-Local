## 1. FUNDAMENTOS DE PROGRAMACIÓN

### 1.1 Variables y Tipos de Datos
Una variable es un espacio en memoria que almacena un valor que puede cambiar.
Tipos básicos: enteros (int), decimales (float), texto (string), booleanos (bool).
En Python: nombre = "Ana", edad = 25, altura = 1.65, activo = True
En JavaScript: let nombre = "Ana"; const edad = 25; var activo = true;
En Java: String nombre = "Ana"; int edad = 25; boolean activo = true;

### 1.2 Estructuras de datos
Listas/Arreglos: colección ordenada [1,2,3]
Diccionarios/Objetos: pares clave-valor {"nombre":"Ana","edad":25}
Conjuntos: elementos únicos {1,2,3}
Tuplas: colección inmutable (1,2,3)

### 1.3 Operadores
Aritméticos: + (suma), - (resta), * (multiplicación), / (división), % (módulo), ** (potencia)
Comparación: == (igual), != (diferente), < (menor), > (mayor), <= (menor o igual), >= (mayor o igual)
Lógicos: and (y), or (o), not (no)
Asignación: =, +=, -=, *=, /=

## 3. FUNCIONES

### 3.1 Definición y uso

Parámetros por defecto: def saludar(nombre="Mundo")

Uso con map: cuadrados = list(map(lambda x: x**2, numeros))

### 3.3 Decoradores
def decorador(funcion):
    def wrapper(*args, **kwargs):
        print("Antes de llamar")
        resultado = funcion(*args, **kwargs)
        print("Después de llamar")
        return resultado
    return wrapper

@decorador
def mi_funcion():
    print("Ejecutando")

### 3.4 Generadores
def generador(n):
    for i in range(n):
        yield i  # Genera valores uno a uno, ahorrando memoria
Uso: for valor in generador(1000000): print(valor)

## 4. PROGRAMACIÓN ORIENTADA A OBJETOS (POO)

### 4.1 Clases y objetos
class Persona:
    # Constructor
    def __init__(self, nombre, edad):
        self.nombre = nombre
        self.edad = edad
    
    # Método
    def saludar(self):
        return f"Hola, soy {self.nombre}"
    
    # Método de clase
    @classmethod
    def desde_nacimiento(cls, nombre, año):
        edad = 2025 - año
        return cls(nombre, edad)
    
    # Método estático
    @staticmethod
    def es_mayor(edad):
        return edad >= 18

### 4.2 Herencia
class Estudiante(Persona):
    def __init__(self, nombre, edad, carrera):
        super().__init__(nombre, edad)
        self.carrera = carrera
    
    def saludar(self):  # Sobrescritura
        return f"Hola, soy {self.nombre}, estudio {self.carrera}"

### 4.3 Encapsulamiento
Atributo privado (convención): self._privado
Atributo privado (name mangling): self.__muy_privado
Property para getter/setter:
    @property
    def edad(self):
        return self._edad
    
    @edad.setter
    def edad(self, valor):
        if valor >= 0:
            self._edad = valor

## 8. ALGORITMOS Y ESTRUCTURAS DE DATOS

### 8.1 Complejidad algorítmica

O(n) - lineal (recorrido simple)
O(n log n) - linealítmico (ordenamiento eficiente)
O(n²) - cuadrático (bucles anidados)
O(2^n) - exponencial (Fibonacci recursivo)

### 8.2 Búsqueda binaria
def busqueda_binaria(arr, objetivo):
    izquierda, derecha = 0, len(arr)-1
    while izquierda <= derecha:
        medio = (izquierda + derecha) // 2
        if arr[medio] == objetivo:
            return medio
        elif arr[medio] < objetivo:
            izquierda = medio + 1
        else:
            derecha = medio - 1
    return -1

### 8.3 Ordenamiento burbuja
def bubble_sort(arr):
    n = len(arr)
    for i in range(n):
        for j in range(0, n-i-1):
            if arr[j] > arr[j+1]:
                arr[j], arr[j+1] = arr[j+1], arr[j]
    return arr

### 8.4 Recursividad
def factorial(n):
    if n <= 1:
        return 1
    return n * factorial(n-1)

def fibonacci(n):
    if n <= 1:
        return n
    return fibonacci(n-1) + fibonacci(n-2)

## 12. CONCEPTOS DE RAG (RETRIEVAL-AUGMENTED GENERATION)

### 12.1 Qué es RAG
RAG combina búsqueda de información con generación de IA.
Pasos: 1) Usuario pregunta, 2) Buscar documentos relevantes, 3) Crear contexto, 4) IA responde basada en contexto
Ventajas: respuestas precisas, fuentes verificables, información actualizada

### 12.2 Componentes clave
Embeddings: vectores numéricos que representan texto
Chunking: dividir documentos en fragmentos pequeños (500-1000 caracteres)
Vector DB: base de datos que guarda y busca vectores
Similitud coseno: mide qué tan similar es un texto a otro
Top-K: número de fragmentos relevantes a recuperar (3-5)
